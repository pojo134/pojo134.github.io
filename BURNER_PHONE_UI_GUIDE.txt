================================================================================
                         COLOR CODING
================================================================================

Battery Levels:
  ██████████ (10-3)  = GREEN  (healthy)
  ██░░░░░░░░ (2-1)   = RED    (critical)

Heat Levels:
  0-50%   = GREEN → YELLOW gradient
  50-100% = YELLOW → RED gradient

Contact Borders:
  GREEN = Available (can use)
  RED   = Disabled (insufficient battery or heat too high)
  PINK  = Selected (targeting mode)

UI Borders:
  GREEN = Active/Unlocked
  GRAY  = Locked (no Rolodex)
  PINK  = Targeting mode

================================================================================
                         KEYBOARD/MOUSE
================================================================================

MOUSE ACTIONS:
  - Click contact button → Select contact
  - Click driver in leaderboard → Use contact on driver
  - Hover contact → Show tooltip
  - Hover driver (when targeting) → Highlight row

NO KEYBOARD SHORTCUTS (Mouse-only interface)

================================================================================
                      TECHNICAL SPECIFICATIONS
================================================================================

UI Position: (610, 420, 180x160)
Battery Display: 10 bars, 14px wide each
Heat Bar: 160px wide, 8px tall
Contact Buttons: 170px wide, 20px tall, 22px spacing
Notification: 400px wide, 60px tall, centered top
Tooltip: 140px wide, 40px tall, right of contact

Update Frequency: 60 FPS
Heat Decay Rate: 2 per second
Notification Duration: 3 seconds (500ms fade in/out)
